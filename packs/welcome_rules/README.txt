Welcome & Rules Datapack
========================

Install:
- Put welcome_rules.zip in your world/datapacks folder.
- Run /reload.

Player command:
/trigger rules

Behaviour:
- Players see the welcome message once.
- The clickable rules button opens the rules immediately.
- Players can use /trigger rules any time after joining.

To reset the welcome message for one player:
tag <player> remove welcome_rules_seen

To reset for everyone:
tag @a remove welcome_rules_seen
